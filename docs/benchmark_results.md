# Route Optimization Benchmark

## Experiment setup

- Cases: **100**
- Delivery stops per case: **10**
- Total nodes including depot: **11**
- Random seed: **42**
- ETA matrix: **real XGBoost model predictions**
- Hill Climbing: **randomized initial route**
- Exact solver: **Held-Karp dynamic programming**
- Route type: **open route; no return to depot**

## Results

| Metric | Result |
|---|---:|
| Cases | 100 |
| Stops per case | 10 |
| Hill Climbing suboptimal cases | 94 / 100 |
| Hill Climbing suboptimality | 94.00% |
| Mean optimality gap | 0.77% |
| Maximum optimality gap | 5.13% |
| Mean Hill Climbing runtime | 3.624 ms |
| Mean Held-Karp runtime | 26.831 ms |
| Mean ETA matrix build time | 566.482 ms |
| Clipped directed legs | 490 / 11000 |
| Clipped-leg share | 4.45% |

## Interpretation

Held-Karp is treated as the exact reference solution for these benchmark cases.

A Hill Climbing case is considered suboptimal when its route cost is greater than the Held-Karp route cost by more than 1e-9.

The optimality gap is calculated as:

`(Hill Climbing cost - Held-Karp cost) / Held-Karp cost × 100`

The clipped-leg share measures how often generated geographic distances fall outside the model's training distance range of 1.47–20.97 km. These cases are important because distance clipping can make different geographic legs receive similar model inputs.
